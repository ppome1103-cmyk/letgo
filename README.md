# 🐾 길냥이체험기

> 오늘 하루, 우리 동네 고양이로 살아보기

폰 브라우저에서 바로 돌아가는 3D 고양이 동네 탐험 게임이에요.
빌라 골목, 초록 옥상, 실외기, 편의점, 놀이터, 전깃줄, 은행나무가 있는 한국 동네를 고양이가 되어 돌아다녀요.

## 오늘의 할 일
- 🐟 생선 간식 20개 모으기
- 📦 박스 3곳에 쏙 들어가기
- 🕊️ 비둘기 5마리 놀래키기
- 👵 츄르 할머니 찾아 야옹하기 (매번 다른 곳에 계심)
- 🏢 제일 높은 옥상(햇살맨션) 오르기
- ☀️ 햇볕 자리에서 식빵 굽기
- 🦋 나비 3마리 잡기

## 조작
| | 폰 | PC |
|---|---|---|
| 걷기 | 화면 왼쪽 드래그 | WASD / 방향키 (Shift: 살금살금) |
| 둘러보기 | 화면 오른쪽 드래그 | 마우스 드래그, 휠: 줌 |
| 점프 | 🐾 버튼 (꾹 누르면 높이) | 스페이스 |
| 야옹 | 😺 버튼 | E |

## 실행
빌드 과정 없이 정적 파일만으로 돌아가요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 구조
```
index.html        화면 UI, 스타일
src/main.js       게임 진행, 카메라, 낮/밤, 미션
src/world.js      동네 자동 생성 + 충돌 판정
src/cat.js        고양이 모델과 애니메이션
src/player.js     이동, 점프, 충돌 처리
src/input.js      가상 조이스틱 / 키보드 / 마우스
src/entities.js   생선, 비둘기, 나비, 행인, 할머니, 박스, 햇볕
src/audio.js      효과음 / 배경음 (코드로 합성)
src/ui.js         알림, 말풍선, 미니맵
vendor/           three.js r170 (MIT)
```

폰 성능을 위해 건물, 창문, 실외기, 나무를 인스턴싱으로 묶어서 화면 전체를 약 60번의 드로우콜로 그려요.
프레임이 떨어지면 해상도를 자동으로 낮춰요.
